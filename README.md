# Via

Track all of your upcoming booked travel — flights, trains, buses, ferries, cruises, car rentals — in one place.

## Getting started

Open `index.html` in any modern browser. That's it — no install or build step.

## Features

- **Add tickets** with type, carrier, route, departure/arrival times, flight/train number, confirmation code, seat, price, booking link, and notes.
- **Upcoming list** sorted by departure with a live countdown (trips within 7 days are highlighted).
- **Past trips** move to their own section automatically once you've arrived.
- **Search & filter** by any field (city, carrier, confirmation code…) or by travel type.
- **Add to calendar** — download any ticket as an `.ics` file for Google Calendar, Apple Calendar, or Outlook.
- **Export / Import** a JSON backup to move your trips between browsers or devices.

## Data

Trips are stored in your browser's `localStorage` on the device you use. Use **Export** regularly to keep a backup.
